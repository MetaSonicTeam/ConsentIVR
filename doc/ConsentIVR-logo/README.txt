ConsentIVR — logo system (Powered by MetaSonic)
================================================

The mark: a violet tile holding a voice waveform whose bars sit on a checkmark —
voice + consent in one shape.

mark/
  consentivr-mark.svg                 Vector mark (tile). consentivr-mark-violet-no-tile.svg = bars only.
  consentivr-mark-{1024,512,256,64}.png

lockup/
  consentivr-horizontal-{light,dark}(.png, @2x, @4x)            Mark + wordmark + tagline + POWERED BY MetaSonic.
  consentivr-horizontal-transparent-for-{light,dark}-bg(...)   Same, transparent.
  consentivr-horizontal-{light,dark}-no-endorsement@2x.png     Without the MetaSonic line.
  consentivr-stacked-*                                          Centered version.

powered-by/
  powered-by-metasonic-{light,dark}(.png, @2x)   Footer/badge pill for sites, docs and the dashboard.

icons/
  consentivr-app-icon-1024.png        Rounded app icon.
  consentivr-telegram-botpic-640.png  Telegram operator-console bot photo (/setuserpic).
  favicon-32.png, favicon-16.png

Colours   Violet #7C3AED · Lilac (dark mode) #A78BFA · Deep #4C1D95 · Ink #0F0A2A
MetaSonic Cyan #2EC5FF → Blue #1D5BFF (mark + "Sonic"), used only in the endorsement.
Type      Wordmark: Inter Display ExtraBold. Tagline / endorsement: Poppins.
          (The ConsentIVR site uses Archivo/IBM Plex and MetaSonic uses Plus Jakarta Sans; neither
           was installable here, so the PNGs use the closest available fonts.)
